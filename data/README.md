# Dataset notes
The local reference is Microplastic.v5i.yolov8, Roboflow Universe version 5, YOLOv8 format. Metadata reports 6,003 annotated images: 4,942 train, 708 validation and 353 test. Classes: Fibre, Film, Fragment, microbeads.
The dataset lists a CC BY 4.0 license. Preserve attribution/license if redistributing the data or trained model. The dataset is not copied into Git; set DATASET_YAML to its local data.yaml. Confirm exact class spelling and attribution before publication.
